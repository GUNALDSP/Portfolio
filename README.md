## ⚡ Cache Optimization
To improve loading speed:
- Assets like images, CSS, and JS are cached by the browser.
- Update file names (e.g., `style.v2.css`) if you make major changes to force refresh.
- For GitHub Pages, caching is handled automatically, but you can use **meta tags** in your HTML for control:

```html
<meta http-equiv="Cache-Control" content="max-age=31536000, must-revalidate">
